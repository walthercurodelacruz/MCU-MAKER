**Esquema de Trabajo Multi-Equipo:**
- **Rama `Team_Windows`:** Responsable de estabilidad en Windows 10/11 x64, binarios nativos `.exe`, runtime QEMU `.dll`, empaquetado con Inno Setup (`MCU-Maker-Setup-v1.2.0.exe`) y pruebas locales en PowerShell (`scripts/qa-local.ps1`).
- **Rama `Team_Linux`:** Responsable de compatibilidad en distribuciones basadas en Debian/Ubuntu (`.deb`) y Fedora/RHEL/openSUSE (`.rpm`), runtime QEMU `.so` y pruebas locales en Bash (`scripts/qa-local.sh`).

## 1. Nomenclatura de Códigos de Bugs / Issues

| Prefijo | Categoría / Alcance | Rama Principal |
| :--- | :--- | :--- |
| **`QA-SEC-XXX`** | Vulnerabilidades de seguridad (Path Traversal, XSS, Open Proxy, DoS/Panic) | Transversal (`Team_Windows` / `Team_Linux`) |
| **`QA-CORE-XXX`** | Defectos funcionales del backend y worker en Rust (`mcu-maker-server`, `mcu-maker-worker`) | Transversal (`Team_Windows` / `Team_Linux`) |
| **`QA-WIN-XXX`** | Defectos específicos de Windows, Launcher Desktop (`eframe`/`egui`) e instalador `.exe` | `Team_Windows` |
| **`QA-LIN-XXX`** | Defectos específicos de Linux, instaladores `.deb` / `.rpm` y AppImage | `Team_Linux` |
| **`QA-VSC-XXX`** | Defectos de la extensión de VS Code (`vscode-extension/`) | Transversal |
| **`QA-FE-XXX`** | Defectos de contratos de API y deuda técnica en Frontend (`frontend/`) | Transversal |
| **`QA-CAT-XXX`** | Ajustes del catálogo oficial de placas y componentes | Transversal |
| **`QA-IOT-XXX`** | Pasarela IoT LAN, proxy HTTP y estado Wi-Fi de simulación | Transversal |
| **`QA-QA-XXX`** | Infraestructura de pruebas locales y automatización de control de calidad | Transversal |
